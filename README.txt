JEE Sunday Test PWA

Install on Samsung SM-T225:
1. Host this folder on any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the HTTPS URL in Chrome on the tablet.
3. Chrome menu -> Install app / Add to Home screen.
4. The app then works offline after first load.

Features: 45 questions, 90-minute timer, +4/-1 marking, navigator, local answer/timer persistence, tablet/phone responsive UI, offline cache.
